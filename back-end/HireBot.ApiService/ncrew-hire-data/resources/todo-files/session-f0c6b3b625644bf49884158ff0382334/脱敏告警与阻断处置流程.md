# 脱敏告警与阻断处置流程

## 1. 流程目标

当系统识别到敏感信息被展示、导出、上传、外发或用于模型调用时，自动进行脱敏、告警或阻断，并形成可追溯的处置记录。

## 2. 触发场景

| 场景        | 示例                  | 处理方式     |
| --------- | ------------------- | -------- |
| 页面展示敏感字段  | 展示手机号、身份证号          | 自动脱敏     |
| 批量导出客户数据  | 导出客户名单、联系方式         | 审批/告警    |
| 上传含敏感信息文件 | 上传客户名单、合同、身份证图片     | 检测后提示或阻断 |
| 外发敏感内容    | 邮件/接口发送高敏字段         | 告警或阻断    |
| 模型调用含敏感数据 | Prompt中包含手机号、身份证、密钥 | 脱敏或阻断    |
| 日志写入敏感字段  | 日志中记录密码、Token       | 阻断并告警    |

## 3. 处置等级

| 等级   | 条件                | 系统动作  | 人工动作      |
| ---- | ----------------- | ----- | --------- |
| 低风险  | L1/L2少量字段         | 自动脱敏  | 无需处理或定期复查 |
| 中风险  | L2/L3字段批量出现       | 脱敏并告警 | 业务负责人确认用途 |
| 高风险  | L3大量数据或疑似越权导出     | 阻断并告警 | 安全/合规人员复核 |
| 严重风险 | L4信息、密钥、密码、身份证等外发 | 立即阻断  | 启动安全事件流程  |

## 4. 标准处置流程

1. **识别**

   * 系统检测文本、文件、接口、日志中的敏感字段。
   * 判断字段类型和敏感等级。

2. **脱敏/阻断**

   * L2：默认展示脱敏。
   * L3：根据场景脱敏、审批或告警。
   * L4：默认阻断，禁止明文流转。

3. **告警通知**

   * 通知数据负责人、系统负责人或安全管理员。
   * 告警内容包括：触发人、时间、系统、字段类型、风险等级、处理结果。

4. **人工复核**

   * 判断是否为正常业务使用。
   * 判断是否需要放行、补充审批或升级事件。

5. **处置闭环**

   * 记录处理结论。
   * 更新规则或白名单。
   * 必要时进行权限调整和人员提醒。

## 5. 告警记录模板

| 字段    | 内容                  |
| ----- | ------------------- |
| 告警编号  | 自动生成                |
| 触发时间  | YYYY-MM-DD HH:mm:ss |
| 触发人   | 用户/系统账号             |
| 所属系统  | 业务系统名称              |
| 触发场景  | 展示/导出/上传/外发/模型调用/日志 |
| 敏感类型  | 手机号/身份证/密钥/合同金额等    |
| 敏感级别  | L1/L2/L3/L4         |
| 系统动作  | 放行/脱敏/告警/阻断         |
| 处置负责人 | 数据负责人/安全负责人         |
| 处置结论  | 正常业务/误报/违规/待确认      |

## 6. SLA建议

| 风险等级 | 响应时限  | 关闭时限  |
| ---- | ----- | ----- |
| 低风险  | 1个工作日 | 3个工作日 |
| 中风险  | 4小时内  | 1个工作日 |
| 高风险  | 1小时内  | 4小时内  |
| 严重风险 | 立即响应  | 当日闭环  |

## 7. 处置原则

* 能脱敏则不明文展示。
* 能最小化使用则不全量使用。
* 无业务必要不导出、不外发。
* 所有高敏操作必须留痕。
* 阻断规则优先保护数据安全，误报后再优化规则。
