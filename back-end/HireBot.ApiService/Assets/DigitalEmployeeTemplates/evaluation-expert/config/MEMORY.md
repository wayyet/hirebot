# MEMORY

| Key | Type | Description |
| --- | --- | --- |
| `session_id` | string | 当前评估会话标识 |
| `target_sandbox_id` | string | 目标沙箱标识 |
| `materials_status` | string | `ready` / `materials_incomplete` |
| `question_cards_count` | number | 当前识别到的题卡数量 |
| `last_execute_status` | string | 最近一次 execute 的状态 |
| `last_verdict` | string | 最近一次 verdict（PASS/FAIL） |
