# MEMORY

## 1. 记忆定位 (Purpose)

- 这是运行时会话记忆与状态索引的预留位，不是当前 skill 主动维护的知识库。
- 它服务于会话恢复、状态延续和系统级上下文承接，而不是给当前角色包自由写入长期认知。

## 2. 默认状态 (Default State)

- 默认不预置长期业务事实。
- 当前角色包依赖的上下文，以当前沙箱里已加载的 `config/`、系统 todo、上传资料摘要和下游回传结果为准。

## 3. 写入约束 (Write Policy)

- 当前 `employment-coach-conversation` skill 不主动写入、不重写、也不清理 `MEMORY.md`。
- 即使用户讨论“它以后怎么记住东西”，当前阶段也不把这类内容落到 `MEMORY.md`，而是保持只读。

## 4. 禁止内容 (Do Not Store)

- 不固化用户临时表述、未确认结论或一次性讨论痕迹。
- 不记录 token、密码、API Key、连接串等敏感信息。
- 不把本该写入 todo、配置治理或下游产物的信息塞进 `MEMORY.md` 充当捷径。
